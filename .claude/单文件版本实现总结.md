## 🎯 新功能特性

### 一键启动
双击 `thrift-perf-tool.exe` 即可：
1. 启动 HTTP 服务(端口 11064)
2. 自动打开默认浏览器
3. 显示控制台日志窗口

### 跨平台浏览器启动
- Windows: `cmd /c start <url>`
- macOS: `open <url>`
- Linux: `xdg-open <url>`

### 实时日志
控制台显示：
- Gin 框架路由注册信息
- 服务启动地址
- 浏览器启动状态
- HTTP 请求日志

## 🎉 实现效果

### 用户体验提升
- **之前**: 需要 exe + web 目录，手动打开浏览器，手动输入地址
- **现在**: 只需双击 exe，自动完成所有启动步骤

### 部署简化
- **之前**: 需要打包两个目录，确保相对路径正确
- **现在**: 只需复制一个 exe 文件

### 维护便捷
- **之前**: 前端修改需要同步 web 目录
- **现在**: 前端修改后重新编译即可

## 🔧 重新编译步骤

如需修改代码后重新编译:

```bash
# 1. 确保 web 目录在正确位置
# backend/cmd/web/ (必须)

# 2. 进入 backend 目录
cd backend

# 3. 编译
go build -o ../thrift-perf-tool.exe ./cmd/main.go

# 4. (可选) 缩小体积
go build -ldflags="-s -w" -o ../thrift-perf-tool.exe ./cmd/main.go
```
